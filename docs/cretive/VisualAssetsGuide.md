# Visual Assets Guide

Todos los recursos visuales deberán seguir estas reglas.

---

MARCO

Elegante.

Muy fino.

No brillante.

No grueso.

---

FLORES

Color crema.

Acuarela.

Nunca saturadas.

Nunca competirán con el contenido.

---

TEXTURA

Papel algodón.

Muy sutil.

---

BRILLOS

Muy pequeños.

Lentos.

Color dorado.

Aparecer aleatoriamente.

No más de 4 simultáneamente.

---

LÍNEAS

Delgadas.

Mucho aire.

---

ORNAMENTOS

Solo si aportan elegancia.

Nunca utilizar elementos únicamente decorativos.

Todo deberá tener intención narrativa.

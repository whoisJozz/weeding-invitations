---

# Visión

No estamos desarrollando una invitación digital.

Estamos construyendo una experiencia cinematográfica.

El usuario deberá sentir que sostiene una invitación física entre sus manos.

Todo el sitio deberá transmitir calma.

Elegancia.

Respiración.

Luz.

Texturas.

Movimiento natural.

---

# Principios

Menos elementos.

Más intención.

Menos animaciones.

Más narrativa.

Menos efectos.

Más emoción.

---

# Regla Editorial

Cada animación deberá contar una historia.

Si una animación existe únicamente porque "se ve bonita"

Debe eliminarse.

---

# El Sobre

El sobre es el protagonista.

Nunca deberá competir con ningún elemento.

Durante la introducción toda la atención deberá dirigirse hacia él.

---

# La Leyenda

"Toca para abrir"

No es un botón.

Es una invitación.

Debe sentirse elegante.

Ligera.

Respirar lentamente.

Debe integrarse al video.

Nunca cubrir el sello.

Nunca competir con él.

---

# Hero

El Hero no aparece.

El Hero emerge.

El usuario debe sentir que atraviesa el sobre y descubre la invitación.

---

# Motion

Todos los movimientos deberán sentirse físicos.

Nunca robóticos.

Nunca mecánicos.

Nunca bruscos.

---

# UX

El usuario jamás deberá pensar:

"Estoy navegando un sitio."

Debe pensar:

"Estoy abriendo una invitación."

---

# Regla Final

Si una decisión mejora el código pero empeora la experiencia...

Se rechaza.

Si una decisión mejora la experiencia aunque implique un poco más de trabajo...

Se aprueba.

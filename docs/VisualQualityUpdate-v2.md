# Visual Quality Standard v2

Nueva filosofía visual

El usuario nunca debe pensar:

"Qué bonita página."

Debe pensar:

"Qué hermosa invitación."

Toda decisión visual deberá responder:

¿Esto parece una invitación de lujo?

Si la respuesta es NO...

No se implementa.

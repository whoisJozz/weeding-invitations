# ACTO I

## Escena 1

El usuario abre el sitio.

No aparece una página.

Aparece una mesa.

Sobre ella descansa un sobre elegante.

El tiempo parece detenerse.

El video permanece inmóvil.

Una leyenda aparece lentamente.

"Toca para abrir"

El usuario toca.

La leyenda desaparece.

El sobre cobra vida.

La cámara se acerca.

La música comienza.

Todo se desvanece.

---

## Escena 2

Silencio.

Aparece una portada editorial.

No una invitación.

Una portada.

Respira.

Mucho espacio blanco.

Mucho aire.

El usuario contempla.

---

## Escena 3

La portada comienza a construirse.

No aparece completa.

Cada elemento surge lentamente.

Marco.

↓

Flores.

↓

Nombres.

↓

Fecha.

↓

Lugar.

↓

Todo parece impreso frente al usuario.

Comienza el Acto II.

Cambios

1.

Eliminar cualquier sensación de "layout web".

Debe sentirse como una invitación física.

2.

Las flores deberán:

entrar lentamente

opacity

0 → 0.22

duración

4 segundos

3.

Los nombres deben conservar el protagonismo absoluto.

4.

El marco deberá verse mucho más fino.

Actualmente:

1px

Nuevo:

0.6px

Color

rgba(200,162,74,.25)

5.

Agregar muchísimo aire.

Más espacio negativo.

No llenar la pantalla.

6.

Los sparkles deberán aparecer únicamente:

cada 5-7 segundos

máximo 2 simultáneos

casi imperceptibles

No queremos glitter.

Queremos polvo dorado.

7.

El fondo deberá permanecer completamente limpio.

No agregar texturas.

No agregar patrones.

No agregar sombras.

8.

Las flores deberán sobresalir ligeramente del marco.

Nunca quedar totalmente dentro.

Sensación

Debe sentirse como si hubieran sido pintadas sobre el papel.

Definition of Done

□ Hero editorial

□ Flores elegantes

□ Marco refinado

□ Sparkles mínimos

□ Mucho espacio negativo

□ Identidad visual consistente

□ Sin apariencia de sitio web

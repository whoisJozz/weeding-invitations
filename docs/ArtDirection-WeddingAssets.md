# Art Direction
## Wedding Assets

Versión 1.0

---

# Objetivo

Crear una identidad visual única para la invitación.

Todos los recursos gráficos deberán pertenecer al mismo universo artístico.

No se permitirá mezclar recursos de diferentes estilos.

---

# Estilo

Editorial.

Minimalista.

Romántico.

Cinematográfico.

Acuarela.

Luxury.

---

# Flores

Tipo:

Peonías.

Complementos:

- hojas de eucalipto
- ramas delicadas
- pequeñas hojas beige

---

# Colores

Marfil

Beige arena

Taupe

Dorado tenue

Verde grisáceo muy desaturado

---

# Saturación

Muy baja.

Las flores nunca deben competir con el contenido.

---

# Opacidad

Entre 10% y 18%.

---

# Ubicación

Superior izquierda

Inferior derecha

Nunca centradas.

Nunca completamente visibles.

Siempre parcialmente fuera del marco.

---

# Resolución

Desktop

3000 px

Mobile

2000 px

Exportación:

WEBP

Transparencia

---

# Separadores

Crear una rama horizontal muy fina para separar actos.

Nunca utilizar líneas negras.

---

# Ornamentos

Generar pequeños adornos dorados.

Inspiración:

Invitaciones de lujo.

No barroco.

No victoriano.

Elegancia contemporánea.

---

# Sparkles

SVG.

Muy pequeños.

Sin glow exagerado.

Color:

#E7D3A4

---

# Restricción

Gemini únicamente deberá integrar estos recursos.

No deberá sustituirlos por otros.

No deberá buscar imágenes externas.

Todos los recursos pertenecen al Design System del proyecto.

# RFC-015

## Editorial Architecture Upgrade

### Motivo

La sección dejó de comportarse como una lista.

Ahora debe sentirse como un capítulo editorial de la invitación.

---

## Filosofía

No queremos una página web.

Queremos una revista.

---

## Principios

Mucho espacio.

Pocas líneas.

Contenido perfectamente alineado.

Ritmo vertical constante.

Nada comprimido.

Nada saturado.

---

## Regla de Oro

Cada bloque debe poder imprimirse individualmente y seguir viéndose elegante.

Si un screenshot de cualquier bloque parece una invitación independiente...

La arquitectura está correcta.

---

## Regla Mobile

No sacrificar legibilidad por intentar mantener columnas.

Mobile siempre prioriza lectura.

Desktop prioriza composición.

---

## Compatibilidad

Debe funcionar igual en:

Chrome

Safari

Firefox

Android Chrome

iPhone Safari

Sin media queries excesivas.

Con arquitectura limpia.

# RFC-008
## Editorial Hero Final

Estado:
PROPOSED

Autor:
Creative Director (ChatGPT)

Objetivo
--------

A partir de este RFC se congela la identidad visual del Hero.

Las nuevas ilustraciones florales pasan a formar parte oficial del sistema visual del proyecto.

No deberán sustituirse por imágenes genéricas ni por recursos descargados de internet.

Estos elementos serán utilizados durante toda la experiencia.

Assets oficiales

assets/images/floral/

    flowers-top-left.png

    flowers-bottom-right.png

Características

• Acuarela
• Fondo transparente
• Crema
• Verde grisáceo
• Dorado muy sutil
• Baja saturación

Nunca competirán con el contenido.

Siempre serán elementos editoriales.

Reglas

No deberán superar:

25% de opacidad

No deberán tener sombras.

No deberán rotar durante la experiencia.

No deberán animarse constantemente.

Únicamente aparecerán mediante fade.

El protagonismo siempre será:

Los nombres

No las flores.

Aprobado para implementación.

# Objetivo

A partir de este Sprint, el proyecto deja de centrarse únicamente en implementar funcionalidades.

La prioridad absoluta será construir una experiencia emocional y cinematográfica.

Cada decisión técnica deberá justificarse desde el punto de vista de la experiencia del usuario.

---

# Nuevo Rol del Lead Front-End Engineer

Además de programar, deberá pensar como:

• UX Designer

• Motion Designer

• Interaction Designer

• Front-End Engineer

No deberá limitarse a traducir requerimientos.

Deberá analizarlos.

Si detecta una solución visualmente superior deberá proponerla antes de implementarla.

---

# Filosofía

No estamos desarrollando un sitio web.

Estamos construyendo una experiencia digital.

La diferencia es fundamental.

Todo deberá sentirse natural.

Nada deberá recordar al usuario que está utilizando un navegador.

---

# Regla de Oro

Antes de escribir código deberá responder internamente:

"¿Esto mejora la experiencia del usuario?"

Si la respuesta es NO...

Debe buscar otra solución.

---

# Prioridades

1. UX

2. Storytelling

3. Motion Design

4. Performance

5. Código

Nunca al revés.

---

# Definition of Done

Cada funcionalidad deberá sentirse elegante.

No solamente funcionar.

# RFC-017

## Nombre

Epílogo Editorial

"Con Gratitud"

---

## Objetivo

La lista de familiares, padrinos y acompañantes dejará de presentarse como un listado técnico.

A partir de este Sprint pasará a formar parte del cierre emocional de la invitación.

Debe sentirse como un agradecimiento.

Nunca como un directorio.

---

## Filosofía

El usuario ya:

vio la historia.

vio la fotografía.

vio la fecha.

vio el lugar.

vio el dress code.

vio la mesa de regalos.

confirmó asistencia.

Ahora únicamente queda agradecer.

Este acto deberá transmitir calma.

---

## Restricciones

No reutilizar la antigua sección de padrinos.

Construir una escena completamente nueva.

No utilizar cards.

No utilizar grids.

No utilizar listas largas visibles.

Toda la información deberá permanecer colapsada.

---

## Arquitectura

Nueva escena independiente.

No modificar escenas anteriores.

No romper navegación.

No romper ScrollTrigger.

---

## Recursos

No requiere recursos nuevos.

No requiere imágenes.

No requiere iconografía.

Todo deberá resolverse con CSS y GSAP.

# RFC-012
## Editorial Story Flow

Estado

Aprobado

---

Objetivo

Mantener toda la invitación como una única experiencia continua.

No construir secciones independientes.

Cada nuevo acto debe sentirse como la continuación natural del anterior.

---

Reglas

No crear componentes duplicados.

No duplicar CSS.

No duplicar managers.

No duplicar animaciones.

Reutilizar siempre que sea posible.

---

Si algún recurso hace falta

NO usar placeholders.

NO improvisar.

Solicitar el recurso.

---

Todos los cambios deberán mantener

60 FPS

Sin Layout Shift

Sin CLS

Sin saltos visuales

---

Compatibilidad

Safari

Chrome

Android

Firefox

Edge

---

Entrega

Gemini deberá indicar:

Archivos modificados

Archivos nuevos

Archivos eliminados

Justificación técnica

Justificación UX

Pendientes

Riesgos

# Visual Quality Standard

> "We are not building a website.
We are designing a cinematic experience."

---

# Filosofía

Toda decisión visual deberá responder a la siguiente pregunta:

¿Esto parece una página web?

Si la respuesta es sí, la solución debe replantearse.

---

# Identidad visual

La experiencia debe transmitir:

Elegancia.

Calma.

Minimalismo.

Lujo.

Editorial.

Exclusividad.

Nunca ostentación.

# Principios

## 1.

Mucho espacio negativo.

Los elementos deben respirar.

Nunca saturar la pantalla.

---

## 2.

Las animaciones deben sentirse naturales.

No utilizar rebotes exagerados.

No utilizar efectos llamativos.

---

## 3.

La interfaz debe desaparecer.

Nunca debe sentirse como una aplicación.

Debe sentirse como una invitación física.

---

## 4.

Cada transición debe tener un propósito.

Nunca animar por animar.

# Componentes prohibidos

Botones HTML por defecto.

Checkboxes.

Inputs sin estilizar.

Alert().

Confirm().

Prompt().

Fondos negros.

Sombras exageradas.

Gradientes agresivos.

Animaciones bruscas.

Bordes por defecto.

---

# Componentes permitidos

Texto editorial.

Microanimaciones.

Fade.

Movimiento suave.

Scroll cinematográfico.

Tipografía protagonista.

Espacio negativo.

---

# Motion

Toda animación deberá responder a una intención.

Ejemplo:

Aparecer.

Desaparecer.

Revelar.

Guiar.

Nunca distraer.

---

# Video

El video es parte de la experiencia.

No es un recurso multimedia aislado.

Debe integrarse naturalmente con el resto de la narrativa.

---

# Audio

La música será un hilo conductor.

No un efecto.

Debe acompañar toda la experiencia.

---

# Responsive

El diseño se construirá tomando como referencia una composición vertical 9:16.

Posteriormente se adaptará a otros formatos.

Nunca al revés.

---

# Definition of Premium

Una experiencia premium cumple con los siguientes principios:

- Parece una pieza editorial.
- El usuario olvida que está navegando un sitio web.
- Todo movimiento tiene intención.
- La tipografía tiene protagonismo.
- El espacio negativo comunica elegancia.
- La interacción es intuitiva y silenciosa.

---

# Regla de Oro

No estamos construyendo una página web.

Estamos diseñando la experiencia digital de una invitación de boda.
